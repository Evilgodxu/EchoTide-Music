# 2026-09-15 封面进出页闪占位符修复

## 根因
`ui/component/SystemThumbnail.kt` 的 `rememberSystemThumbnail` 用
`produceState(initialValue = null)` 驱动取图。页面进出重建时组合节点重新进入
composition，produceState 一律从 null（占位符）起帧，即便内存缓存已命中该略缩图，
也要等 IO 协程跑一圈后才回填成图，故智能歌单专辑/艺术家列表等封面在进出页时先闪占位符。

## 变更
- `SystemThumbnail.kt`：produceState 前用 `remember(audioUri, sizePx, coverRevision)`
  从 `SystemThumbnailCache` 同步取回命中位图作为 initialValue；未命中仍走原 IO 解码回填。
  键带 coverRevision：封面重写已清空缓存，避免旧图作为初始值顶出。

## 坑
- 初始值同步读取仅适用于内存缓存（SystemThumbnailCache）路径；EmbeddedCoverCache 无同步读，
  非索引曲目仍会有一次占位帧，本次不扩范围。
