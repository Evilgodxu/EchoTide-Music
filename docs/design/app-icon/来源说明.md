# 应用图标来源

图标由小红书作者「新建文件夹001」（[主页](https://xhslink.cn/o/1dZk6ujEe8N)，ID 5282478962）绘制，
已获授权用于本应用；致谢见仓库根目录的 README。

本目录保存作者交付的原稿与各尺寸导出。应用图标走自适应图标：`app/src/main/res/mipmap`
下的 `ic_launcher.xml` 组合纯色背景与前景位图，minSdk 34 起不再需要方形 / 圆形整套位图，
它们仅作存档保留在此。

- `原图.jpg`：原稿，1254 × 1254。
- `mipmap-<密度>/ic_launcher.webp`：方形图标，48 / 72 / 96 / 144 / 192 五档，已不参与打包。
- `mipmap-<密度>/ic_launcher_round.webp`：圆形图标，同五档，圆外透明，已不参与打包。
- `app/src/main/res/mipmap-<密度>/ic_launcher_foreground.webp`：自适应图标前景，108dp 画布内放
  72dp 画面（四周透明），由 `原图.jpg` 缩放导出，保证圆形遮罩下画幅不被裁。
- `google-play/icon.webp`：512 × 512，商店列表图标。
- `google-play/feature-graphic.webp`：1024 × 1024 方图。Play 的横版宣传图规范是 1024 × 500，
  这张不能直接当宣传图用。
