# 应用图标来源

图标由小红书作者「新建文件夹001」（[主页](https://xhslink.cn/o/1dZk6ujEe8N)，ID 5282478962）绘制，
已获授权用于本应用；致谢见仓库根目录的 README。

本目录保存作者交付的原稿与各尺寸导出，配置在 `app/src/main/res/mipmap-*` 的那些位图即从这里取用，
逐字节相同，未做重采样。

- `原图.jpg`：原稿，1254 × 1254。
- `mipmap-<密度>/ic_launcher.webp`：方形图标，48 / 72 / 96 / 144 / 192 五档。
- `mipmap-<密度>/ic_launcher_round.webp`：圆形图标，同五档，圆外透明。
- `google-play/icon.webp`：512 × 512，商店列表图标。
- `google-play/feature-graphic.webp`：1024 × 1024 方图。Play 的横版宣传图规范是 1024 × 500，
  这张不能直接当宣传图用。
